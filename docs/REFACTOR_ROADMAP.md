# MobileBox: 5 大阶段 · 15 个可真机验证的小步计划 (Micro-Steps Roadmap)

> **源工程参考**：[sayxiaoyan/Box](https://github.com/sayxiaoyan/Box) (TVBox 电视端开源项目)  
> **重构目标**：重新构建专属于个人安卓手机的原生触控应用 [353154/MobileBox](https://github.com/353154/MobileBox)（非简单 Fork，独立重写）  
> **实机环境**：已连接手机 `CPH2723` (Android 17, arm64-v8a)

本文档将五大重构阶段拆解为 **15 个独立交付、步步可验证的小步**。  
每个小步完成后，系统均会自动编译 APK 推送至您的手机 `CPH2723`，您只需拿起手机按照“验证指南”进行验收。

## 阶段二：架构升级与交互重绘 (Architecture & UI Rebuild)
- [x] **Step 2.1【底部四栏导航与现代化 UI 体系】**：Compose HorizontalPager + MD3 柔和色彩 + Material You 动态取色
  - *验证方法*：手机底部清晰展示【首页】、【分类】、【直播】、【设置】四个 Tab，支持左右横滑手势平滑切换；支持深浅色与动态壁纸取色，状态栏文字自适应；分类双层级 FilterChip 防误触；全局统一 2:3 黄金比例 StandardPosterCard 与真实网络海报；极简自适应 ModernToastMessage 提示弹窗已真机验收通过。
- [x] **Step 2.2【点播瀑布流海报与下拉刷新 + 主题色系统】**：双列触控网格 + 下拉刷新物理推移与回弹 + iOS 仿生开关 + HSV 圆形色盘 + 极光背景
  - *验证方法*：
    1. 首页与分类页双列海报流畅触控滚动，`animateItem` 柔和渐入；
    2. 下拉刷新阻尼拉伸，页面内容跟随手指下移（`translationY = verticalOffset`），松手弹性回弹，指示器平滑缩放淡出无残留；
    3. 全局 iOS 风格 `CupertinoSwitch`（51dp×31dp 亮绿/主题色轨迹 + 纯白滑块物理弹簧位移）；
    4. 全局主题引擎支持默认、动态、自定义 HSV 圆形色盘（`ColorWheel` 极坐标取色），支持实时 Hex 显示与全局即时变色；
    5. 全局背景采用无卡顿纯硬件加速“主题色极光渐变 (Aurora Glow)”，随主题色与深浅色模式动态流光联动。已真机验收通过。
- [ ] **Step 2.3【挖孔屏与沉浸式避让】**：Edge-to-Edge 全面屏与手势条适配
  - *验证方法*：应用内容向上延伸至状态栏顶部，但文字与按键自动避开前置摄像头挖孔，底部避让小白条。
- [ ] **Step 2.4【陀螺仪 3D 视差】**：硬件传感器驱动海报悬浮倾斜
  - *验证方法*：双手倾斜或晃动手机，海报卡片产生随手部动作实时响应的 3D 悬浮与景深位移。

## 阶段三：全能播放器引擎改造 (Advanced Player Engine)
- [ ] **Step 3.1【双核解码引擎】**：IJK + MPV 双核抽象与首播跑通
  - *验证方法*：点击任意视频卡片，拉起移动端播放器，秒开硬件解码播放，支持在设置里热切换解码器。
- [ ] **Step 3.2【全屏触控全手势】**：左亮右音 + 水平 Seek 进度
  - *验证方法*：全屏播放时，左半屏上下滑调亮度，右半屏上下滑调音量，横向滑动出现进度预览，双击暂停。
- [ ] **Step 3.3【Danmaku 弹幕与 PiP 画中画】**：弹幕覆盖与系统级悬浮窗
  - *验证方法*：画面上飘过弹幕；按 Home 键或侧滑回桌面，画面自动缩为小悬浮窗继续播放。
- [ ] **Step 3.4【Anime4K / FSR 画质增强】**：GLSL 超分着色器挂载
  - *验证方法*：在播放器菜单开启“超画质”，画面线条与清晰度明显增强。

## 阶段四：数据层与网络增强 (Data & Network Enhancements)
- [ ] **Step 4.1【Spider 协程调度】**：真实数据源接入与异步流拉取
  - *验证方法*：填入 TVBox 订阅源，首页实时流式刷出真实电影/剧集分类与海报，无任何界面卡顿。
- [ ] **Step 4.2【去广告与 TMDB 智能刮削】**：M3U8 广告切片剥离 + 高清元数据
  - *验证方法*：带赌博/跑马灯片头的视频开播秒跳过广告；低清影片自动匹配出 TMDB 中文 4K 背景与评分。
- [ ] **Step 4.3【WorkManager 离线缓存】**：后台后台断点下载
  - *验证方法*：点击“离线下载”，通知栏显示下载进度条；下载完成后切断手机 Wi-Fi/移动网络，本地依然流畅秒播。
